# 🧑‍💻 Learn Basic CSS by Building a Cafe Menu

In this project, I built a responsive cafe menu using basic HTML and CSS. It helped me understand core styling concepts such as layout, typography, color schemes, and responsive design principles.

## 🚀 Live Preview  
👉 [**CodePen**](https://codepen.io/onyxwizard/pen/gbpjRKM)

## 📚 What I Learned in CSS

### ✅ Internal CSS Styling
- Used an internal `<style>` block to apply CSS directly within the HTML file.
- Organized CSS rules for better readability and maintainability.

### 🎨 Selectors & Syntax
- Practiced using **element selectors**, **class selectors (.)**, and **ID selectors (#)** to target specific HTML elements.
- Applied multiple styles in one rule using proper CSS syntax:
  ```css
  selector {
    property: value;
  }
  ```

### 🖌 Color & Backgrounds
- Used **named colors**, **hex codes**, and **RGB values** to style backgrounds and text.
- Set background colors for different sections of the menu using `background-color`.

### 🔤 Typography & Text Styling
- Controlled font appearance using:
  - `font-family`
  - `font-size`
  - `font-weight`
  - `text-align`
- Styled headings and paragraphs to improve visual hierarchy.

### 📐 The Box Model
- Gained hands-on experience with the box model components:
  - `margin`, `padding`, `border`
- Adjusted spacing around elements to enhance layout and readability.

### 🧱 Layout & Positioning
- Structured content using semantic HTML and styled it with CSS for clarity.
- Experimented with `display: flex` for arranging menu items horizontally.
- Used `flex-wrap` and `justify-content` to manage alignment and responsiveness.

### 🔄 Responsive Design Basics
- Implemented **media queries** to adjust layout and styling for smaller screens.
- Changed font sizes and layout flow depending on screen width to ensure mobile-friendliness.

### 🧩 Classes & Reusability
- Created reusable classes like `.item`, `.price`, and `.dessert` to avoid repetition.
- Applied consistent styling across similar elements using class selectors.

### 🧹 Debugging & Clean Code
- Inspected and debugged layout issues using browser developer tools.
- Kept CSS clean and well-commented to help with future edits or updates.
